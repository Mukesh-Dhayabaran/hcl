# Library Waitlist Management

## Objective

Demonstrate Java Collections Framework implementations through a simple library waitlist management program.

## Collections Used

- **ArrayList:** Stores registered members and supports index-based access.
- **LinkedHashSet:** Prevents duplicate member registrations while preserving insertion order.
- **ArrayDeque:** Maintains the normal waitlist in FIFO order.
- **PriorityQueue:** Serves priority members according to natural alphabetical ordering in the current implementation.
- **Iterator.remove():** Safely removes a member while iterating through the member list.

## Features

- Register members and reject duplicates.
- Add registered members to the priority queue.
- Serve the next member from the normal waitlist.
- Serve the next priority member.
- Remove members from the collections.
- Display the current collection contents.
